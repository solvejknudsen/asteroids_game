# astroid game

Building an asteroid game in python using pygame is my second [Boot.dev](https://www.boot.dev) project!

Initialization Steps

1. Create uv project in parent folder
	`uv init asteriod_game`
2. Pin project's python version inside project directory
	`uv python pin 3.13`
3. Create virtual environment at top level of project directory
	`uv venv`
4. Activate the virtual environment
	`source .venv/bin/activate`
5. Add pygame library as dependency
	`uv add pygame==2.6.1`
